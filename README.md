# 우리 쿠폰, 진짜 남는 장사인가?

## 3. 분석 방법
1. **분석용 마진 정의:** 순수익 = 실질금액(할인 반영) × (1 − GST), 마진율 = 순수익 ÷ 할인 전 매출 *(회계상 이익이 아닌 분석용 지표)*
2. **쿠폰의존 세그먼트:** 쿠폰 사용 비중 기준으로 무의존 / 저의존 / 중의존 / 고의존 / 완전의존 5단계로 분류
3. **RFM × 가입구분:** RFM 점수와 가입기간(12개월 기준)을 교차해 **이탈위험 고객**(기존 가입 + RFM 낮음)을 정의
4. **카테고리 믹스 보정:** 카테고리 구성 차이를 보정한 뒤에도 마진 격차가 남는지 확인
5. **액션 임팩트 시뮬레이션:** 고의존 고객의 할인을 완화했을 때의 예상 순수익 증분 추정

## 4. 핵심 결과
- **중의존 고객이 전체 순수익의 52.3%를 만들었다.** 449명(30.6%)이 1인당 약 60라인을 구매하며 총량을 만들었다. 쿠폰을 쓴다고 모두 수익이 낮은 고객은 아니다.
- **순수익의 55.3%가 Nest-USA 카테고리에서 나왔다.** 수익은 한 카테고리에 집중됐지만, 세그먼트별 선호 카테고리는 달랐다.
- **이탈위험 고객(311명)의 42.44%가 고·완전의존이었다.** 전체 평균(32.4%)의 약 1.31배다.
- **이탈위험 고객의 상품라인당 순수익은 36.8% 낮았다.** ($47.11 vs $74.57)
- **카테고리 믹스를 보정해도 마진 격차(−0.401%p)가 남았다.** 카테고리 구성만이 아니라 할인 이용 패턴과 관련이 있을 가능성이 있다. *(인과관계는 아님)*

## 5. 제안 CRM 액션
> 결론: **거래량이 큰 고의존 고객부터**, 쿠폰을 한 번에 끊지 않고 **단계적으로 줄이면서** 비할인 혜택으로 대체한다.

| 구분 | 대상 | 실행 방안 |
|---|---|---|
| **MAIN** | 고의존 고객 | 할인 빈도·강도를 단계적으로 완화하고, 개인화·정가 상품 추천으로 대체 |
| **SUB** | 완전의존 고객 | 규모가 작아(예상증분 $875) 소규모·저비용 실험으로 반응만 확인 |
| **TEST** | 고의존 고객 무작위 분할 | 쿠폰 제공군(현행 유지) vs 비할인 혜택군 A/B 테스트 |
| **KPI** | — | 재구매율 · 쿠폰 적용률 · 객단가 · 분석용 마진율 |

**실행 단계 (MAIN)**
1. **타겟 추출:** 쿠폰의존 세그먼트가 '고의존'인 고객을 추출하고, 그중 **이탈위험 고객**(기존 가입 + RFM 낮음)은 별도 그룹으로 표시한다. 이탈위험 고객은 할인 축소에 더 민감할 수 있어 완화 속도를 늦게 가져간다.
2. **1단계 – 빈도 완화:** 쿠폰 발송 횟수부터 줄인다. 할인율은 유지해 고객이 체감하는 혜택 변화를 최소화한다.
3. **2단계 – 강도 완화:** 1단계에서 재구매율이 유지되면 할인율을 낮춘다.
4. **대체 혜택:** 줄어든 쿠폰 자리에 세그먼트별 선호 카테고리 기반의 **개인화·정가 상품 추천**, 무료배송 같은 **비할인 혜택**을 넣는다.
5. **판단 기준:** 비할인 혜택군의 **분석용 마진율·객단가가 오르면서 재구매율이 쿠폰 제공군 대비 크게 떨어지지 않으면** 대상을 확대하고, 재구매율이 떨어지면 완화 폭을 되돌린다.

**개선 여지 (가정 기반 시뮬레이션)**
- 고의존 고객의 상품라인당 순수익이 저의존 수준으로 오른다고 가정하면 약 **$28K** 증분 *(상품라인당 $69.85 → $72.30 × 11,469라인)*
- 실제 캠페인 성과가 아닌 **개선 여지 추정치**이며, 위 A/B 테스트로 검증이 필요하다.

## 6. 한계
- 원가 데이터가 없어 실제 이익이 아닌 **분석용 마진**으로 계산했다.
- '이탈위험'은 실제 이탈 예측이 아닌 **RFM 기준 분류**다.
- 관찰 데이터라 쿠폰과 수익 사이의 **인과관계는 확인할 수 없다.**
- 액션 효과는 A/B 테스트로 검증이 필요한 **가정 기반 추정치**다.
